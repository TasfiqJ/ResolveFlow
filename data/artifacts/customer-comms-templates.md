# Customer communication templates (synthetic)

Owner: Support Operations. Classification: public.

Status page templates are pre-approved so responders do not draft under pressure. Investigating:
state the affected capability and the time the impact began, and commit to a next update time.
Identified: state that a cause is known without naming an internal component or vendor.
Monitoring: state that a fix is applied and impact is receding. Resolved: state duration and
whether any customer action is required.

Never publish internal service names, vendor names, ticket identifiers, error codes, or headcount
detail. Never state a cause before it is confirmed; a retracted cause costs more trust than a
slower update.

Update cadence for a severity-high payments incident is every 30 minutes even when there is no
new information. "No change yet, next update at HH:MM" is a valid update.
